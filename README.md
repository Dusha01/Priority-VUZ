# Фронтенд сайта "Приоритет-2030"

Этот проект представляет собой фронтенд-часть сайта Дальневосточного государственного университета путей сообщения (ДВГУПС), посвященного программе стратегического академического лидерства "Приоритет-2030".

## О проекте

Проект разработан с использованием **SvelteKit** - современного фреймворка для создания веб-приложений. Он включает в себя:

- Главную страницу с информацией о программе развития университета
- Страницу с документами и отчетами
- Адаптивный дизайн с использованием **Tailwind CSS**
- Компонентную архитектуру для легкого сопровождения и расширения

## Архитектура проекта

```
src/
├── lib/
│   ├── components/
│   │   ├── common/          # Общие компоненты (Header, Footer)
│   │   ├── home/            # Компоненты главной страницы
│   │   │   ├── ui/          # UI-компоненты для главной страницы
│   │   │   ├── StrategicProjects/  # Компоненты стратегических проектов
│   │   │   └── ...          # Другие секции главной страницы
│   │   └── documents/       # Компоненты страницы документов
│   ├── layouts/             # Макеты страниц
│   ├── pages/               # Страничные компоненты
│   └── index.ts             # Экспорты компонентов
├── routes/                  # Маршруты SvelteKit
└── static/                  # Статические файлы
```

### Ключевые компоненты

- **home/**: Секции главной страницы (Main, AboutProgram, Mission, Team, DevelopmentProgram, StrategicProjects)
- **common/**: Переиспользуемые компоненты (Header, Footer)
- **documents/**: Компоненты для страницы документов
- **ui/**: Специфичные UI-компоненты (ArrowDown, PriorityIcon, ScrollToTop)

## Технологии

- **SvelteKit** - Фреймворк для веб-приложений
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS** - CSS-фреймворк для стилизации
- **Vite** - Инструмент сборки

## Запуск проекта

### Предварительные требования

- Node.js (версия 18 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Проект будет доступен по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр сборки

```bash
npm run preview
```

### Проверка кода

```bash
npm run check
```

## Структура маршрутов

- `/` - Главная страница
- `/documents` - Страница с документами

## Разработка

Проект использует компонентную архитектуру Svelte. Все компоненты экспортируются через `src/lib/index.ts` для удобного импорта.

Для добавления новых секций на главную страницу:
1. Создайте компонент в `src/lib/components/home/`
2. Добавьте экспорт в `src/lib/index.ts`
3. Импортируйте и используйте в `src/lib/pages/MainPage.svelte`
